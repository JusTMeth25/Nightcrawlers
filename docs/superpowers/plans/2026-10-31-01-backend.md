# Nightcrawlers — Piano 01: Backend (agente Backend)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** API Spring Boot sicura per account, salvataggi, run, sblocchi e Ripperdoc, conforme a `docs/api/openapi.yaml`.

**Architecture:** Package per funzionalità sotto `com.nightcrawlers`. PostgreSQL con Flyway. Spring Security stateless con access JWT HS256 (15 min) e refresh token opaco ruotato in cookie. I dati di gioco arrivano da `src/main/resources/gamedata/*.json` (generati dal coordinatore, sola lettura). Il server calcola sblocchi e ricompense.

**Tech Stack:** Spring Boot 4.1.1, Java 25, Spring Web MVC, Data JPA, Security, OAuth2 Resource Server, Validation, Flyway (+ `flyway-database-postgresql`), PostgreSQL 18, Bucket4j (`com.bucket4j:bucket4j_jdk17-core`), Spring Mail, BouncyCastle `bcprov-jdk18on` (Argon2), Lombok, JUnit 5, Mockito, Testcontainers (`spring-boot-testcontainers`, modulo PostgreSQL), Spring Security Test. Spring Boot 4 usa Jackson 3 (`tools.jackson`).

**Spec:** `docs/superpowers/specs/2026-10-31-nightcrawlers-design.md` (sezioni 2.10, 2.11, 4, 5)

## Global Constraints

- Lavori solo in `BE/**`, esclusi `BE/Dockerfile` e `BE/src/main/resources/gamedata/**`. Per modifiche ai contratti (`docs/api/openapi.yaml`, `FE/src/shared/**`) o ai dati di gioco chiedi al coordinatore.
- Nessun commit o file riporta strumenti AI come autori o co-autori.
- Contratto: `docs/api/openapi.yaml` e `FE/src/shared/api-contract.ts` (piano 00, Task 4). Nomi dei campi JSON identici (camelCase).
- Segreti solo da env o `application-local.properties` (ignorato da git). Fornisci `application-local.properties.example` senza valori reali.
- Password: Argon2id, lunghezza 12–128, rifiuto delle 10.000 più comuni.
- Access token 15 min; refresh token 30 giorni, 256 bit, hash SHA-256 in DB, ruotato a ogni uso.
- Errori sempre `application/problem+json`, mai stack trace.
- Copertura ≥ 80% sui service (JaCoCo, verificata da `./mvnw verify`).
- Test di integrazione con Testcontainers (Docker Desktop richiesto).

## Review Focus

1. Due richieste `/auth/refresh` concorrenti con lo stesso token: una sola riesce; la seconda è trattata come riuso e revoca la famiglia. Test in Task 6.
2. Email con maiuscole o spazi (`" Mario@Mail.IT "`): normalizzata (trim + minuscolo) in registrazione, login e forgot-password. Test in Task 4.
3. `/runs/{id}/end` chiamato su una run di un altro utente: 404, mai 403 (nessuna rivelazione dell'esistenza). Test in Task 11.
4. Acquisti Ripperdoc concorrenti con €$ sufficienti per uno solo: un solo acquisto riesce (lock ottimistico o `SELECT … FOR UPDATE`). Test in Task 12.
5. `DELETE /me` cancella tutte le righe collegate (token, run, statistiche, audit con `user_id` impostato a null). Test in Task 13.
