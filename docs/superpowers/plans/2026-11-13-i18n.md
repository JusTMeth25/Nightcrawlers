# Multilingual Support (it, en, es) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make UI, game data texts, server errors and emails available in Italian, English and Spanish.

**Architecture:** The coordinator updates the shared contract first (C1). Then an FE agent (worktree `../nc-ui`, branch `feat/i18n-fe`) and a BE agent (worktree `../nc-backend`, branch `feat/i18n-be`) work in parallel on disjoint files. The coordinator merges, adds the e2e test and deploys (C2).

**Tech Stack:** React 19 + zustand (FE), Spring Boot 4 MessageSource + LocaleResolver, Thymeleaf message expressions, Flyway (BE), Playwright (e2e).

**Spec:** `docs/superpowers/specs/2026-11-13-i18n-design.md`

## Global Constraints

- `Locale = 'it' | 'en' | 'es'`; data fallback `it`; unsupported browser → `en`; server default `it`.
- No AI attribution anywhere (no Co-Authored-By, no "Generated with", no AI names).
- Agents edit only their owned files (FE: `FE/src/ui/**`, `FE/src/api/**`, `FE/src/App.tsx`, `FE/src/App.test.tsx`, `FE/src/main.tsx`, `FE/src/index.css`, plus `FE/src/data/i18n/**` and `FE/src/data/i18n.test.ts` for this plan; BE: `BE/**` except `BE/Dockerfile` and `BE/src/main/resources/gamedata/**`).
- Translations are natural, game-appropriate, consistent terminology across UI, data and emails (e.g. "Eurodollars"/"Eurodólares", "Ripperdoc", "Codex", "Cyberpsychosis"/"Ciberpsicosis"). Legal texts (disclaimer, privacy) keep the same meaning in every language.
- Placeholders `{name}` are identical across languages.
- TDD: each test seen failing before its implementation.

## Review Focus

1. Options saved by the current app (version 1, no `locale`) are migrated, not reset: autoAim, volumes etc. survive and locale is detected. → FE Task F1 test.
2. A logged-in user on a second device whose browser is English must not have the account switched to Italian at login (device choice wins, server updated only on explicit change). → FE Task F4 test.
3. `Accept-Language: fr-FR,fr;q=0.9` or a malformed header gives Italian server messages, never a 500. → BE Task B2 test.
4. Reset password requested from a Spanish browser for an English account sends the email in English. → BE Task B3 test.
5. Changing language from the pause menu must not remount the play screen mid-run. → FE Task F4 test.
